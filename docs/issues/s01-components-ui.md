# Hand-maintained roster restates a declared set — components/UI

> **Related:** [issues/README](README.md) · [tools/audit](../../tools/audit/README.md) · [rule source](../../docs/issues/core-stat-single-source.md)

## What breaks

Rule `S01` — hand-maintained roster restates a declared set — holds in 7 places under `components/UI`. Each one is listed below with the evidence the audit required before it would record a fail.

The clearest case: PRIORITIES hand-lists all four members of the `ZonePriority` union with no compiler or test link back to it, so a fifth priority added to the union would leave this dropdown short.
